# Security Fundamentals

Keamanan jaringan bukan sekadar menambahkan password. Seorang network engineer harus memahami **apa yang dilindungi, ancaman apa yang mungkin terjadi, kontrol mana yang relevan, dan bagaimana membuktikan kontrol tersebut bekerja**.

Course ini menyusun domain Security Fundamentals CCNA menjadi lima lesson yang dapat dipelajari secara berurutan. Setiap lesson ditutup dengan knowledge check. Jawaban benar akan menambah XP, menyelesaikan lesson, memperbarui progress, dan membuka badge lokal.

<Callout type="remember" title="Progress tersimpan di perangkatmu">
Versi awal belum memakai akun atau database. XP, streak, badge, dan lesson yang selesai disimpan pada browser yang sedang kamu gunakan.
</Callout>

## Peta course

| Lesson | Fokus | Hasil belajar |
| --- | --- | --- |
| 1 | Konsep keamanan dan risiko | membedakan threat, vulnerability, exploit, dan mitigation |
| 2 | Hardening, akses aman, dan AAA | mengamankan akses administratif menggunakan secret dan SSH |
| 3 | Keamanan Layer 2 | menjelaskan port security, DHCP snooping, dan DAI |
| 4 | Access Control List IPv4 | merancang, memasang, dan memverifikasi ACL dasar |
| 5 | VPN, wireless, dan verifikasi | membandingkan VPN, WPA2/WPA3, serta membuat test matrix |

## Cara belajar

1. Baca satu lesson sampai memahami alur keputusannya.
2. Coba contoh command pada lab milikmu sendiri ketika siap.
3. Jawab knowledge check di akhir lesson.
4. Gunakan penjelasan feedback untuk memperbaiki pemahaman.
5. Lanjutkan ke lesson berikutnya melalui navigasi bawah halaman.
