# Introduction


Modul ini menjelaskan bagaimana network automation diaktifkan melalui RESTful APIs dan configuration management tools. Automation adalah tren utama di industri networking yang mengubah cara jaringan dikelola dari manual ke programmatic.

## 14.0.1 Why should I take this module?

Kamu perlu belajar modul ini karena:
- network automation adalah masa depan networking — mengurangi manual work, meningkatkan konsistensi
- memahami APIs dan data formats artinya bisa berinteraksi dengan network devices secara programmatic
- configuration management tools memungkinkan kamu mengelola ribuan devices secara efisien
- intent-based networking adalah konsep baru yang mengubah cara jaringan didesain dan dioperasikan

## 14.0.2 What will I learn to do in this module?

Di modul ini, kamu akan belajar untuk:
- memahami konsep dasar automation
- memahami dan membandingkan data formats: JSON, YAML, XML
- memahami konsep APIs dan RESTful APIs
- memahami configuration management tools: Ansible, Puppet, Chef, SaltStack
- memahami intent-based networking dan Cisco DNA Center
