# Introduction


Modul ini bertujuan untuk mengajarkan kamu bagaimana **mengimplementasikan IPv4 ACL** untuk memfilter traffic dan mengamankan akses administratif. Intinya: dari teori ke praktik.

## 5.0.1 Why should I take this module?

Karena di dunia nyata, ACL bukan hanya diketahui tapi harus **bisa dikonfigurasi**. Sebagai network engineer, kamu akan sering diminta untuk:
- memblokir akses dari host/network tertentu
- mengamankan remote access (Telnet/SSH)
- memfilter traffic berdasarkan port dan protocol
- memodifikasi ACL yang sudah ada

## 5.0.2 What will I learn to do in this module?

Di modul ini, kamu akan belajar untuk:
- mengkonfigurasi **standard IPv4 ACL**
- memodifikasi ACL yang sudah ada
- mengamankan **VTY ports** dengan standard ACL
- mengkonfigurasi **extended IPv4 ACL**
