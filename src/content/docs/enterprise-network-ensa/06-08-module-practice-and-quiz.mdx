# Command Reference modul 6

| Command | Fungsi |
|---|---|
| `ip nat inside source static <local> <global>` | Buat static NAT mapping |
| `ip nat pool <name> <start> <end> netmask <mask>` | Buat NAT pool |
| `ip nat inside source list <acl> pool <pool>` | Dynamic NAT: bind ACL ke pool |
| `ip nat inside source list <acl> interface <if> overload` | PAT: gunakan alamat interface |
| `ip nat inside source list <acl> pool <pool> overload` | PAT: gunakan pool |
| `ip nat inside` | Tandai interface sebagai inside |
| `ip nat outside` | Tandai interface sebagai outside |
| `show ip nat translations` | Lihat NAT table |
| `show ip nat statistics` | Lihat statistik NAT |
| `clear ip nat translation *` | Hapus semua dynamic entries |
| `clear ip nat statistics` | Reset statistik |
