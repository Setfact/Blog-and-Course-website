# Modern WAN Connectivity


Bagian ini membahas teknologi WAN modern yang masih aktif digunakan.

## 7.4.1 Modern WANs

![Modern WANs](https://itexamanswers.net/wp-content/uploads/2020/04/Modern-WANs.jpg)

WAN modern lebih fleksibel, cepat, dan cost-effective dibanding teknologi tradisional.

## 7.4.2 Modern WAN Connectivity Options

![Modern WAN Connectivity Options](https://itexamanswers.net/wp-content/uploads/2020/04/Modern-WAN-Connectivity-Options.jpg)

### Tiga kategori utama:
1. **Dedicated Broadband** (Dark Fiber)
2. **Packet-Switched Modern** (Ethernet WAN, MPLS)
3. **Internet-Based Broadband** (DSL, Cable, Wireless)

## 7.4.3 Ethernet WAN

![Ethernet WAN](https://itexamanswers.net/wp-content/uploads/2020/04/Ethernet-WAN.jpg)

**Ethernet WAN** (juga dikenal sebagai **Metro Ethernet**, **EoMPLS**, **VPLS**) menggunakan fiber-optic untuk memperluas Ethernet melewati jarak MAN/WAN.

### Kelebihan:
- **biaya lebih rendah** dari teknologi WAN tradisional
- **integrasi mudah** — same Ethernet semantics dari LAN ke WAN
- **bandwidth tinggi** untuk data, voice, dan video
- **produktivitas meningkat** berkat koneksi yang lebih cepat

## 7.4.4 MPLS

![MPLS](https://itexamanswers.net/wp-content/uploads/2020/04/MPLS.jpg)

**MPLS (Multiprotocol Label Switching)** adalah teknologi switching berbasis label yang menghubungkan client tanpa mempedulikan metode akses mereka.

### Karakteristik MPLS:
- **protocol-agnostic** — bisa membawa traffic IP, Ethernet, ATM, Frame Relay
- menggunakan **label** untuk forwarding (bukan longest prefix match)
- mendukung **QoS** (Quality of Service)
- mendukung **traffic engineering**
- mendukung **VPN** (Layer 3 MPLS VPN, Layer 2 VPN)

### Cara kerja MPLS:
1. Paket masuk ke MPLS network
2. Label ditambahkan ke paket berdasarkan Forwarding Equivalence Class (FEC)
3. Paket dirute berdasarkan label, bukan IP header
4. Label dilepas di ujung jaringan
