# Switch Hardware


Bagian ini membahas kategori, form factor, dan spesifikasi switch Cisco.

## 11.3.1 Switch Categories

### Campus LAN Switches

![Campus LAN Switches](https://itexamanswers.net/wp-content/uploads/2020/04/Campus-LAN-Switches.jpg)

Untuk core, distribution, dan access layer di campus. Contoh: Cisco 2960, 3850, 6800.

### Cloud-Managed Switches

![Cloud-Managed Switches](https://itexamanswers.net/wp-content/uploads/2020/04/Cloud-Managed-Switches.jpg)

Virtual stacking, remote management. Contoh: Cisco Meraki.

### Data Center Switches

![Data Center Switches](https://itexamanswers.net/wp-content/uploads/2020/04/Data-Center-Switches.jpg)

Scalability tinggi untuk data center. Contoh: Cisco Nexus.

### Service Provider Switches

![Service Provider Switches](https://itexamanswers.net/wp-content/uploads/2020/04/Service-Provider-Switches.jpg)

Carrier-grade aggregation/access.

### Virtual Networking

![Virtual Networking](https://itexamanswers.net/wp-content/uploads/2020/04/Virtual-Networking.jpg)

Menambahkan virtualization intelligence. Contoh: Nexus untuk data center.

## 11.3.2 Form Factors

### Fixed Configuration

![Fixed configuration switches](https://itexamanswers.net/wp-content/uploads/2020/04/Fixed-configuration-switches.jpg)

Fitur built-in terbatas. Port dan features sudah ditentukan saat pembelian.

### Modular

![Modular configuration switches](https://itexamanswers.net/wp-content/uploads/2020/04/Modular-configuration-switches.jpg)

Slot untuk line cards yang bisa diganti. Fleksibel untuk upgrade.

### Stackable

![Stackable configuration switches](https://itexamanswers.net/wp-content/uploads/2020/04/Stackable-configuration-switches.jpg)

Beberapa switch beroperasi sebagai **satu logical switch**. Memudahkan manajemen dan scaling.

## 11.3.3 Key Switch Specifications

### Port Density

![Catalyst 9400 Switch](https://itexamanswers.net/wp-content/uploads/2020/04/Catalyst-9400-Switch.jpg)

Jumlah port per switch: 12, 24, 48, atau lebih. Port density harus mendukung perangkat saat ini DAN masa depan.

### Forwarding Rate

![Switch](https://itexamanswers.net/wp-content/uploads/2020/04/Switch.jpg)

Kemampuan switch memproses data. **Wire-speed** = 100 Mbps–100 Gbps per port tanpa packet loss.

### Power over Ethernet (PoE)

![IP Phone](https://itexamanswers.net/wp-content/uploads/2020/04/IP-Phone.jpg)

![WAP](https://itexamanswers.net/wp-content/uploads/2020/04/WAP.jpg)

PoE memungkinkan switch memberi daya ke perangkat melalui kabel Ethernet: IP phones, wireless APs, security cameras.

### Multilayer Switching

![Multilayer Switching](https://itexamanswers.net/wp-content/uploads/2020/04/Multilayer-Switching.jpg)

Multilayer switch menggabungkan kemampuan **Layer 2** (switching) dan **Layer 3** (routing). Ideal untuk core dan distribution layer.

![Cisco Catalyst 2960-C](https://itexamanswers.net/wp-content/uploads/2020/04/Cisco-Catalyst-2960-C.jpg)

## 11.3.4 Business Considerations

| Pertimbangan | Deskripsi |
|---|---|
| **Cost** | Tergantung port, fitur, scalability |
| **Port Density** | Harus mendukung device saat ini dan masa depan |
| **Power** | PoE support; redundant power supplies |
| **Reliability** | Akses jaringan yang kontinu |
| **Port Speed** | Kritis untuk performa end-user |
| **Frame Buffers** | Menangani traffic congestion |
| **Scalability** | Memungkinkan pertumbuhan jaringan |
