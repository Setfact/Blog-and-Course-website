# Router Hardware


Bagian ini membahas kategori dan form factor router Cisco.

## 11.4.1 Router Categories

### Branch Routers

![Branch Routers](https://itexamanswers.net/wp-content/uploads/2020/04/Branch-Routers.jpg)

Optimasi untuk branch WAN/branch services. Contoh: Cisco ISR 4000.

### Network Edge Routers

Performance tinggi untuk campus/data center. Contoh: Cisco ASR 9000.

### Service Provider Routers

![Service Provider Routers](https://itexamanswers.net/wp-content/uploads/2020/04/Service-Provider-Routers.jpg)

Scalable solutions untuk operator. Contoh: Cisco NCS 6000.

### Industrial Routers

![Industrial](https://itexamanswers.net/wp-content/uploads/2020/04/Industrial.jpg)

![Cisco 800 Industrial Integrated Services Router](https://itexamanswers.net/wp-content/uploads/2020/04/Cisco-800-Industrial-Integrated-Services-Router.jpg)

Ruggedized untuk lingkungan keras (pabrik, outdoor). Contoh: Cisco 1100 Series.

## 11.4.2 Form Factors

### Fixed Configuration

![Cisco 900 Series](https://itexamanswers.net/wp-content/uploads/2020/04/Cisco-900-Series.jpg)

Interface built-in, tidak bisa di-upgrade. Cocok untuk branch kecil.

### Modular

Slot untuk interface cards yang bisa diganti sesuai kebutuhan. Contoh: ASR 1000.

### Virtual

![Cisco Network Convergence System 5500 Series Routers](https://itexamanswers.net/wp-content/uploads/2020/04/Cisco-Network-Convergence-System-5500-Series-Routers.jpg)

Router berbasis software yang berjalan di hardware komoditas.

# Kata-kata kunci modul 11

- **Access Layer** — edge jaringan, menghubungkan end devices
- **Distribution Layer** — agregasi, routing, QoS, keamanan
- **Core Layer** — backbone, high-speed connectivity
- **EtherChannel** — link aggregation untuk bandwidth tambahan
- **STP** — Spanning Tree Protocol, mencegah Layer 2 loops
- **PoE** — Power over Ethernet
- **Multilayer Switching** — Layer 2 + Layer 3 dalam satu perangkat
- **Switch Block** — unit desain modular (access + distribution)
- **Router Block** — redundancy dan routing antar switch blocks
- **Failure Domain** — area yang terpengaruh saat komponen gagal
