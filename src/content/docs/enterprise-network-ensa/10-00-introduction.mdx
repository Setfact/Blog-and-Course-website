# Introduction


Modul ini menjelaskan bagaimana mengimplementasikan protokol untuk mengelola jaringan. Sebagai network engineer, kamu harus bisa memantau, mengelola, dan memelihara perangkat jaringan secara efisien.

## 10.0.1 Why should I take this module?

Kamu perlu belajar modul ini karena:
- network management adalah bagian **wajib** dari pekerjaan network engineer
- kamu harus bisa memantau status jaringan secara real-time
- memahami SNMP, Syslog, NTP artinya bisa melakukan **troubleshooting** lebih cepat
- backup dan restore configuration adalah skill dasar yang harus dikuasai

## 10.0.2 What will I learn to do in this module?

Di modul ini, kamu akan belajar untuk:
- mengkonfigurasi CDP dan LLDP untuk device discovery
- mengkonfigurasi NTP untuk sinkronisasi waktu
- memahami SNMP dan cara kerjanya
- mengkonfigurasi Syslog untuk log management
- melakukan backup/restore configuration dan IOS image
- melakukan password recovery
