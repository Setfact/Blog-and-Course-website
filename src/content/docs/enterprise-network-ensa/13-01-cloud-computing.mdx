# Cloud Computing


Bagian ini membahas cloud computing: definisi, manfaat, layanan, dan model.

## 13.1.1 Cloud Overview

![Cloud Overview](https://itexamanswers.net/wp-content/uploads/2020/04/Cloud-Overview.jpg)

### Apa itu Cloud Computing?
**Cloud computing** adalah layanan off-premise yang menyediakan akses on-demand ke shared computing resources. Menggunakan jaringan komputer besar yang bergantung pada virtualization untuk pengiriman resource yang efisien.

### Manfaat Cloud:
| Manfaat | Deskripsi |
|---|---|
| **Akses fleksibel** | Akses data organisasi dari mana saja, kapan saja |
| **Streamline IT** | Berlangganan hanya layanan yang dibutuhkan |
| **Eliminasi equipment** | Mengurangi perangkat onsite, maintenance, management |
| **Biaya lebih rendah** | Mengurangi biaya equipment, energi, ruang, training |
| **Respons cepat** | Merespons peningkatan data demand dengan cepat |
| **Pay-as-you-go** | Mengeluarkan biaya seperti utilitas |

## 13.1.2 Cloud Services

![Cloud Services](https://itexamanswers.net/wp-content/uploads/2020/04/Cloud-Services.jpg)

### 4 Tipe Layanan Cloud (NIST)

| Layanan | Yang dikelola provider | Contoh |
|---|---|---|
| **SaaS** (Software as a Service) | Aplikasi dan layanan | Email, Office 365, Google Workspace |
| **PaaS** (Platform as a Service) | Development tools dan hosting environment | Google App Engine, Heroku |
| **IaaS** (Infrastructure as a Service) | Network equipment, virtualized services, infrastructure | AWS EC2, Azure VM, Google Compute Engine |
| **ITaaS** (IT as a Service) | IT support untuk SaaS/PaaS/IaaS | Managed IT services |

## 13.1.3 Cloud Models

![Cloud Models](https://itexamanswers.net/wp-content/uploads/2020/04/Cloud-Models.jpg)

| Model | Deskripsi |
|---|---|
| **Public** | Tersedia untuk umum, pay-per-use |
| **Private** | Untuk satu organisasi saja, bisa mahal untuk dibangun/dipelihara |
| **Hybrid** | Kombinasi private dan public cloud, dihubungkan oleh satu arsitektur |
| **Community** | Untuk penggunaan eksklusif komunitas tertentu (misal: healthcare untuk HIPAA) |

## 13.1.4 Cloud Computing and Virtualization

![Cloud Computing and Virtualization](https://itexamanswers.net/wp-content/uploads/2020/04/Cloud-Computing-and-Virtualization.jpg)

Virtualization adalah **fondasi cloud computing** — memisahkan OS dari hardware yang mendasarinya, memungkinkan multiple OS berjalan di satu physical server.
