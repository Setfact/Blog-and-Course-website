# Multiaccess OSPF Networks


## 2.3.1 OSPF Network Types

![OSPF Multiaccess Network](https://itexamanswers.net/wp-content/uploads/2020/04/OSPF-Multiaccess-Network.jpg)

- **Point-to-point** = antar dua router, DR/BDR tidak diperlukan
- **Broadcast multiaccess** = banyak router, perlu DR/BDR

## 2.3.2 OSPF Designated Router

![Role of the DR](https://itexamanswers.net/wp-content/uploads/2020/04/Role-of-the-DR.gif)

- **DR (Designated Router)** — pusat pertukaran LSA
- **BDR (Backup Designated Router)** — standby kalau DR gagal
- **DROTHER** — router yang bukan DR/BDR
- Multicast: **224.0.0.5** (all OSPF routers), **224.0.0.6** (DR/BDR only)

## 2.3.4 Verify OSPF Router Roles

### R1 — State DROTHER
```text
R1# show ip ospf interface GigabitEthernet 0/0/0
  Process ID 10, Router ID 1.1.1.1, Network Type BROADCAST, Cost: 1
  Transmit Delay is 1 sec, State DROTHER, Priority 1
  Designated Router (ID) 3.3.3.3, Interface address 192.168.1.3
```

### R2 — State BDR
```text
R2# show ip ospf interface GigabitEthernet 0/0/0
  Process ID 10, Router ID 2.2.2.2, Network Type BROADCAST, Cost: 1
  Transmit Delay is 1 sec, State BDR, Priority 1
  Designated Router (ID) 3.3.3.3, Interface address 192.168.1.3
  Backup Designated router (ID) 2.2.2.2, Interface address 192.168.1.2
```

### R3 — State DR
```text
R3# show ip ospf interface GigabitEthernet 0/0/0
  Process ID 10, Router ID 3.3.3.3, Network Type BROADCAST, Cost: 1

  Designated Router (ID) 3.3.3.3, Interface address 192.168.1.3

```

Neighbor ID     Pri   State           Dead Time   Address         Interface

DROTHER membentuk adjacency penuh ke DR dan BDR, tapi **antar DROTHER tidak saling full adjacency**.

## 2.3.6 Default DR/BDR Election Process

1. **interface priority** tertinggi → DR
2. **interface priority** tertinggi kedua → BDR
3. kalau priority sama, **router ID** tertinggi menang

**Penting:** DR/BDR election **tidak pre-emptive** — router baru dengan priority lebih tinggi tidak otomatis menggusur DR yang sudah terpilih.

## 2.3.8 Adjusting Interface Priority

### Set R1 priority tinggi
```text
R1(config)# interface GigabitEthernet 0/0/0 
R1(config-if)# ip ospf priority 255 
R1(config-if)# end
```

### Set R3 priority 0 (tidak ikut election)
```text
R3(config)# interface GigabitEthernet 0/0/0
R3(config-if)# ip ospf priority 0
R3(config-if)# end
```

### Reset OSPF process
```text
R1# clear ip ospf process
```

### Verifikasi
```text
R1# show ip ospf interface GigabitEthernet 0/0/0
  Transmit Delay is 1 sec, State DR, Priority 255
  Designated Router (ID) 1.1.1.1, Interface address 192.168.1.1
  Backup Designated router (ID) 2.2.2.2, Interface address 192.168.1.2
```

Sekarang R1 (priority 255) menjadi **DR**, R2 (priority 1) menjadi **BDR**, dan R3 (priority 0) tidak ikut election.
