# Command Reference modul 5

| Command | Fungsi |
|---|---|
| `access-list <n> {permit\|deny} ...` | Buat numbered ACL |
| `ip access-list standard <name>` | Buat named standard ACL |
| `ip access-list extended <name>` | Buat named extended ACL |
| `ip access-group <n\|name> {in\|out}` | Apply ACL ke interface |
| `access-class <n\|name> {in\|out}` | Apply ACL ke VTY lines |
| `show access-lists` | Lihat ACL dan statistik |
| `show running-config \| section access-list` | Lihat ACL di running config |
| `clear access-list counters` | Reset statistik match |
| `remark <text>` | Tambahkan komentar di ACL |
| `transport input ssh` | Batasi VTY hanya SSH |
