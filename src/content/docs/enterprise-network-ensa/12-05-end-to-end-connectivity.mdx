# End-to-End Connectivity


Bagian ini membahas troubleshooting konektivitas end-to-end menggunakan pendekatan layered.

## 12.5.1 Components of Troubleshooting End-to-End Connectivity

![Components of Troubleshooting End-to-End Connectivity](https://itexamanswers.net/wp-content/uploads/2020/04/Components-of-Troubleshooting-End-to-End-Connectivity.jpg)

### Komponen yang harus diverifikasi:
1. **Physical** — kabel, port, link status
2. **Data Link** — switch port, VLAN, STP
3. **Network** — IP address, subnet mask, default gateway, routing
4. **Transport** — TCP/UDP ports, ACL, NAT
5. **Application** — DNS, DHCP, service status

## 12.5.3 Step-by-Step Verification

### Step 4: Verify Default Gateway

![Step 4 Verify Default Gateway](https://itexamanswers.net/wp-content/uploads/2020/04/Step-4-Verify-Default-Gateway.jpg)

```text
PC> ipconfig
Default Gateway: 192.168.1.1
```

Pastikan default gateway sudah dikonfigurasi dengan benar.

### Step 5: Verify Correct Path

![Step 5 Verify Correct Path](https://itexamanswers.net/wp-content/uploads/2020/04/Step-5-Verify-Correct-Path.jpg)

```text
Router# show ip route
```

Periksa apakah route ke destination ada di routing table.

![Step 5 Verify Correct Path - 2](https://itexamanswers.net/wp-content/uploads/2020/04/Step-5-Verify-Correct-Path1.jpg)

```text
Router# traceroute 209.165.200.225
```

Identifikasi di mana paket berhenti.

### Step 7: Verify ACLs

![Step 7 Verify ACLs](https://itexamanswers.net/wp-content/uploads/2020/04/Step-7-Verify-ACLs.jpg)

```text
Router# show access-lists
```

Periksa apakah ada ACL yang memblokir traffic.
