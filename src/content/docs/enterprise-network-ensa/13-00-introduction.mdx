# Introduction


Modul ini menjelaskan konsep virtualization jaringan dan bagaimana cloud computing mengubah cara organisasi mengelola infrastruktur IT.

## 13.0.1 Why should I take this module?

Kamu perlu belajar modul ini karena:
- **cloud computing** dan **virtualization** adalah tren utama di industri IT
- SDN mengubah cara jaringan dikelola — dari manual ke **programmable**
- memahami konsep ini artinya siap untuk tren masa depan jaringan

## 13.0.2 What will I learn to do in this module?

Di modul ini, kamu akan belajar untuk:
- memahami cloud computing dan model-modelnya
- memahami virtualization dan hypervisors
- memahami network virtualization dan traffic flow types
- memahami konsep SDN: control plane vs data plane
- mengenal Cisco ACI dan APIC-EM
