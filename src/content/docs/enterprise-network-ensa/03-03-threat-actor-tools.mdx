## 3.3.2 Introduction to Attack Tools

Tools serangan saat ini makin canggih tapi juga makin mudah digunakan. Bahkan orang dengan pengetahuan teknis yang terbatas bisa menjalankan serangan serius menggunakan tools yang sudah tersedia.

![Sophistication of Attack Tools vs. Technical Knowledge](https://itexamanswers.net/wp-content/uploads/2020/04/Sophistication-of-Attack-Tools-vs.-Technical-Knowledge.jpg)

Gambar di atas memperlihatkan tren bahwa tools makin canggih sementara pengetahuan teknis yang dibutuhkan untuk menggunakannya makin rendah. Ini berarti semakin banyak orang yang bisa melakukan serangan.

### Kategori tools yang umum dipakai

| Kategori | Contoh Tools | Fungsi |
|---|---|---|
| **Password Crackers** | John the Ripper, Ophcrack, THC Hydra | Membobol atau melewati password |
| **Wireless Hacking** | Aircrack-ng, Kismet | Menguji keamanan wireless |
| **Network Scanning** | Nmap, SuperScan, Angry IP Scanner | Mendeteksi port terbuka dan layanan |
| **Packet Crafting** | Hping, Scapy | Menguji firewall dengan paket palsu |
| **Packet Sniffers** | Wireshark, Tcpdump | Menangkap dan menganalisis traffic |
| **Exploitation Tools** | Metasploit, Core Impact, SQLMap | Mengeksploitasi vulnerability yang diketahui |
| **Vulnerability Scanners** | Nessus, OpenVAS, SAINT | Memindai sistem untuk vulnerability |
| **Hacking OS** | Kali Linux, BackBox Linux | OS yang sudah dilengkapi tools serangan |

### Kenapa harus paham tools ini?
Bukan untuk dipakai menyerang, tapi untuk **memahami cara kerja attacker** sehingga kamu bisa membangun pertahanan yang lebih baik.

## 3.3.3 Evolution of Security Tools

Tools keamanan terus berevolusi mengikuti perkembangan tools serangan. Defense harus selalu lebih update daripada offense.

## 3.3.4 Attack Types

| Tipe Serangan | Deskripsi |
|---|---|
| **Eavesdropping** | Menangkap dan mendengarkan traffic jaringan |
| **Data Modification** | Mengubah data dalam paket tanpa diketahui pengirim/penerima |
| **IP Spoofing** | Membuat paket dengan IP sumber palsu |
| **Password-Based Attacks** | Membobol password untuk akses tidak sah |
| **DoS** | Membanjiri target supaya layanan tidak bisa diakses |
| **Man-in-the-Middle** | Mencegat komunikasi antara dua pihak |
| **Compromised-Key** | Mencuri kunci enkripsi untuk membuka data terenkripsi |
| **Sniffer Attacks** | Menganalisis paket yang tidak terenkripsi |
