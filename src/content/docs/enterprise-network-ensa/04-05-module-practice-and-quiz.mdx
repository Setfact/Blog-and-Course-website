# Kata-kata kunci modul 4

- **ACL** — Access Control List
- **ACE** — Access Control Entry
- **Implicit Deny** — perintah deny tersembunyi di akhir ACL
- **Wildcard Mask** — mask 32-bit untuk pencocokan alamat
- **Standard ACL** — filter berdasarkan source IP saja
- **Extended ACL** — filter berdasarkan source + destination + port + protocol
- **Numbered ACL** — diidentifikasi oleh nomor
- **Named ACL** — diidentifikasi oleh nama, bisa diedit per baris
- **Packet Filtering** — proses memeriksa dan memutuskan apakah packet boleh lewat
