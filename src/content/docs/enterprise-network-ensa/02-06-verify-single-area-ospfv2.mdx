# Verify Single-Area OSPFv2


## 2.6.1 show ip ospf neighbor (final)
```text
R1# show ip ospf neighbor 
Neighbor ID     Pri   State           Dead Time   Address         Interface
3.3.3.3           0   FULL/  -        00:00:19    10.1.1.13       GigabitEthernet0/0/1
2.2.2.2           0   FULL/  -        00:00:18    10.1.1.6        GigabitEthernet0/0/0
```
State **FULL/  -** (bukan FULL/DR) karena semua link sudah point-to-point.

## 2.6.6 Troubleshooting Dasar

| Problem | Kemungkinan Penyebab |
|---|---|
| Adjacency tidak terbentuk | Area mismatch, timer mismatch, network statement salah |
| Neighbor tapi bukan Full | Authentication mismatch, MTU mismatch, network type beda |
| Route tidak muncul | Network statement tidak cover interface, passive-interface |
| Cost tidak sesuai | Reference bandwidth belum diubah, manual cost belum di-set |
| Default route tidak tersebar | `default-information originate` belum di-run |
