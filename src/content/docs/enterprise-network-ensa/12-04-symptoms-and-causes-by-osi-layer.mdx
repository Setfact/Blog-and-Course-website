# Symptoms and Causes by OSI Layer


Bagian ini membahas gejala dan penyebab umum di setiap layer OSI.

## 12.4.1 Physical Layer Troubleshooting

![Physical Layer Troubleshooting](https://itexamanswers.net/wp-content/uploads/2020/04/Physical-Layer-Troubleshooting.jpg)

### Symptoms:
- Performa rendah
- Kehilangan konektivitas
- CPU usage tinggi
- Console errors

### Common Causes:
- Power failure
- Hardware faults (bad NICs, bad cables)
- Cable faults (kabel putus, connector longgar)
- Interface errors

## 12.4.2 Data Link Layer Troubleshooting

![Data Link Layer Troubleshooting](https://itexamanswers.net/wp-content/uploads/2020/04/Data-Link-Layer-Troubleshooting.jpg)

### Symptoms:
- Tidak bisa ping ke default gateway
- Duplicate IP address errors
- Intermittent connectivity

### Common Causes:
- Duplex mismatch
- Switch port issues
- VLAN misconfiguration
- STP problems
- MAC address table issues

## 12.4.3 Network Layer Troubleshooting

![Network Layer Troubleshooting](https://itexamanswers.net/wp-content/uploads/2020/04/Network-Layer-Troubleshooting.jpg)

### Symptoms:
- Tidak bisa mengakses resource di network lain
- Routing loop
- Intermittent connectivity

### Common Causes:
- IP address misconfiguration
- Subnet mask incorrect
- Default gateway missing
- Routing protocol issues
- ACL blocking traffic

## 12.4.4 Transport Layer Troubleshooting

![Transport Layer Troubleshooting ACLs](https://itexamanswers.net/wp-content/uploads/2020/04/Transport-Layer-Troubleshooting-ACLs.jpg)

![Transport Layer Troubleshooting ACLs - 2](https://itexamanswers.net/wp-content/uploads/2020/04/Transport-Layer-Troubleshooting-ACLs1.jpg)

![Transport Layer Troubleshooting NAT for IPv4](https://itexamanswers.net/wp-content/uploads/2020/04/Transport-Layer-Troubleshooting-NAT-for-IPv4.jpg)

### Symptoms:
- Aplikasi tertentu tidak bisa diakses
- Koneksi terputus secara berkala

### Common Causes:
- ACL blocking specific ports
- NAT issues
- Firewall rules
- TCP/UDP port problems

## 12.4.5 Application Layer Troubleshooting

![Application Layer Troubleshooting](https://itexamanswers.net/wp-content/uploads/2020/04/Application-Layer-Troubleshooting.jpg)

### Symptoms:
- Aplikasi tidak merespons
- Performa aplikasi lambat
- Authentication failures

### Common Causes:
- DNS issues
- DHCP problems
- Service not running
- Software bugs
- Password expired
