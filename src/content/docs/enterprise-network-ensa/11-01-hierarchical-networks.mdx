# Hierarchical Networks


Bagian ini membahas model hierarchical untuk desain jaringan yang scalable.

## 11.1.1 The Need to Scale the Network

![The Need to Scale the Network](https://itexamanswers.net/wp-content/uploads/2020/04/11.1.2-The-Need-to-Scale-the-Network.gif)

### Kebutuhan enterprise network:
- mendukung **aplikasi kritis**
- mendukung **converged network traffic** (data, voice, video)
- mendukung **kebutuhan bisnis yang beragam**
- menyediakan **administrative control** yang terpusat

## 11.1.2 Cisco Borderless Network

![Borderless Switched Networks](https://itexamanswers.net/wp-content/uploads/2020/04/Borderless-Switched-Networks.jpg)

**Cisco Borderless Network** menggabungkan akses wired/wireless dengan manajemen berbasis policy. Memungkinkan konektivitas aman dan reliable dari perangkat mana pun, di mana pun.

## 11.1.3 Hierarchical Network Models

### Three-Tier Model

![Three-Tier Model](https://itexamanswers.net/wp-content/uploads/2020/04/Three-Tier-Model.jpg)

| Layer | Fungsi |
|---|---|
| **Access Layer** | Edge jaringan; menghubungkan end devices ke distribution layer. Menyediakan user access |
| **Distribution Layer** | Mengagregasi access layer; menjalankan routing, QoS, keamanan. Menyediakan high availability |
| **Core Layer** | Backbone jaringan; mengagregasi distribution layers. Menyediakan fault isolation dan high-speed connectivity |

![Three-Tier Example](https://itexamanswers.net/wp-content/uploads/2020/04/Three-Tier-Example.jpg)

### Two-Tier (Collapsed Core) Model

![Two-Tier Model](https://itexamanswers.net/wp-content/uploads/2020/04/Two-Tier-Model.jpg)

Menggabungkan core dan distribution layers. Cocok untuk:
- campus yang lebih kecil
- desain yang disederhanakan
- biaya lebih rendah

![Two-Tier Example](https://itexamanswers.net/wp-content/uploads/2020/04/Two-Tier-Example.jpg)

### Perbandingan

| Aspek | Three-Tier | Two-Tier |
|---|---|---|
| Jumlah layer | 3 (Access, Distribution, Core) | 2 (Access, Core/Distribution) |
| Skala | Large enterprise | Small-medium campus |
| Biaya | Lebih tinggi | Lebih rendah |
| Redundancy | Sangat tinggi | Tinggi |
| Kompleksitas | Tinggi | Sedang |

## 11.1.4 Hierarchical Design Principles

| Prinsip | Deskripsi |
|---|---|
| **Hierarchical** | Menyederhanakan deployment/manajemen, mengurangi fault domain |
| **Modularity** | Memungkinkan expansion tanpa gangguan |
| **Resiliency** | Memastikan network availability |
| **Flexibility** | Memungkinkan load sharing yang efisien |
