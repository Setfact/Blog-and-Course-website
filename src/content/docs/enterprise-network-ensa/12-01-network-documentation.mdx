## 12.1.4 Establish a Network Baseline

**Baseline** adalah gambaran kinerja normal jaringan. Tanpa baseline, kamu tidak bisa membedakan "normal" dari "abnormal".

### 3 Langkah establishing baseline:

![Identify Devices and Ports of Interest](https://itexamanswers.net/wp-content/uploads/2020/04/Identify-Devices-and-Ports-of-Interest.jpg)

**Step 1:** Tentukan data yang ingin dikumpulkan
- Interface utilization
- CPU utilization
- Error rates
- Bandwidth usage

**Step 2:** Identifikasi devices dan ports of interest
- Server kritis
- Router interfaces utama
- User PCs penting

![Determine the Baseline Duration](https://itexamanswers.net/wp-content/uploads/2020/04/Determine-the-Baseline-Duration.jpg)

**Step 3:** Tentukan durasi pengumpulan
- Minimum **7 hari**
- Idealnya **2-6 minggu**
- Hindari periode dengan traffic pattern unik (liburan, event khusus)

### Command untuk data collection

| Command | Fungsi |
|---|---|
| `show version` | Uptime, software/hardware versions |
| `show ip/ipv6 interface brief` | Status interface dan IP addresses |
| `show ip/ipv6 route` | Routing table |
| `show cdp neighbors detail` | Neighbor Cisco yang terhubung |
| `show running-config` | Konfigurasi saat ini |
| `show tech-support` | Info komprehensif untuk support |

<Callout type="remember" title={"Manual collection tidak scalable"}>
Untuk jaringan besar, gunakan **NMS (Network Management System)** untuk pengumpulan data otomatis.
</Callout>
