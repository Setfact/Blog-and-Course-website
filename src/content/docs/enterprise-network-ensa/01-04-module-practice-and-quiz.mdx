# Module Practice and Quiz


Bagian ini berisi latihan dan kuis untuk menguji pemahaman kamu setelah mempelajari seluruh modul.

## 1.4.1 What did I learn in this module?

Setelah selesai modul ini, kamu seharusnya sudah paham:
- apa itu **OSPF**
- kenapa OSPF dipakai
- packet apa saja yang dipakai OSPF
- bagaimana OSPF membentuk adjacency
- bagaimana OSPF membangun LSDB dan routing table
- kenapa **DR** dan **BDR** penting di multiaccess network

## 1.4.2 Module Quiz – Single-Area OSPFv2 Concepts

Kuis ini dipakai untuk mengecek pemahaman kamu terhadap seluruh materi modul 1.

### Fokus kuis biasanya mencakup
- fungsi **Hello packet**
- tujuan **LSU** dan **LSA**
- peran **DR/BDR**
- tahapan adjacency OSPF
- penggunaan **area 0**
- perbedaan **OSPFv2** dan **OSPFv3**

### Kenapa bagian quiz tetap penting di dokumentasi?
Karena quiz itu membantu kamu ngecek apakah kamu cuma “ngehafal istilah” atau benar-benar paham alur kerja OSPF dari awal sampai akhir.
