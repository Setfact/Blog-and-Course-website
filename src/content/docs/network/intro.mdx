## Code Examples

Here is how you might configure a basic interface in Cisco IOS vs Linux:

<Tabs>
  <TabItem label="Cisco IOS">
    ```cisco
    interface GigabitEthernet0/1
     ip address 192.168.1.1 255.255.255.0
     no shutdown
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    ip addr add 192.168.1.1/24 dev eth0
    ip link set eth0 up
    ```
  </TabItem>
</Tabs>
